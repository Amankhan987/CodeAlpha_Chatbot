# CodeAlpha_Chatbot

A simple rule-based chatbot built in Python as part of the CodeAlpha Python Programming Internship.

## Description
The chatbot replies to user messages using predefined rules. Typing "bye" ends the chat.

## Features
- Replies to: hello, how are you, your name, help, bye
- Handles unknown messages with a default reply
- Not case sensitive

## How to Run
1. Install Python
2. Download `chatbot.py`
3. Run in terminal: `python chatbot.py`

## Concepts Used
if-elif, functions, loops, input/output
